# QuestCraft OpenXR dependencies

These LWJGL 3.3.3 JARs are preserved from QuestCraft's Minecraft 1.21.4 Vivecraft distribution. The Java binding includes the Android OpenXR entry points.

Fabric nests these dependencies without unpacking them. The Android launcher supplies the native OpenXR loader and `vloader`.

Upstream: [QuestCraft VivecraftMod](https://github.com/QuestCraftPlusPlus/VivecraftMod/tree/60ffc92889fed3d1a92127b1b66516dd2354bbeb). The LWJGL license is included in [LICENSE.md](../LICENSE.md#lwjgl).
