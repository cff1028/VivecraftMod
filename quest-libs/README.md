# Quest Android OpenXR 绑定

`lwjgl-openxr-quest-3.4.1-compat.1.jar` 来自 FCL `release-0.1.1-20261107`。它沿用 [QuestCraft 的 Android OpenXR API](https://github.com/QuestCraftPlusPlus/lwjgl3/tree/ec0bbebe4379f59fe956c9a79e44d3b09837b134)，按 LWJGL 3.4.1 编译。

Fabric 将其作为嵌套依赖，并补充模块元数据；828 个 class 文件保持原样。Linux、Windows 的 OpenXR native 依赖使用 Maven 上的 LWJGL 3.4.1，Android OpenXR loader 与 `vloader` 由 FCL 提供。

SHA-256：`52e8e0845d4e1c09385fc42822112fd201b557d07957109953ef778fc5c6413a`

来源与修改说明见 [NOTICE](LWJGL-3.4.1-compat-NOTICE.txt)，许可证见 [LWJGL](LWJGL-LICENSE.md) 和 [QuestCraft LWJGL](QuestCraft-LWJGL-LICENSE.md)。
